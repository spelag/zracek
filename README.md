# zracek

Spoznajte Zraček – obesek za ključe, ki vam z enim samim pogledom razkrije trenutno kakovost zraka v vaši okolici in 12-urno napoved. Zasnovan je za vse: od tistih, ki jim sodobna tehnologija ni najbližja, do uporabnikov, ki cenijo hitre in preproste rešitve v vsakdanjem življenju. Uporabljate raje pametno uro? Z obrazom za uro Zraček imate podatke vedno na zapestju. Na naši spletni strani pa lahko preverite tudi, kje v okolici so nove merilne postaje najbolj nujne, glede na dejavnike kot so bližina vrtcov, šol in bolnišnic, ter števila uporabnikov Zračka.
